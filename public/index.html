01 · Extraction
Paginated JSON Ingestion
Scrapy queries Daraz's catalog JSON endpoint with AutoThrottle and randomized delays to extract raw pricing, ratings, sellers, and sales counts.
02 · Transformation
Regex Cleaning & Unit Math
Filters hardware noise, parses weights (g/kg) via regex, classifies roast/coffee types, and computes normalized Rs. / 100g unit economics.
03 · Storage
Idempotent SQLite History
Upserts master product metadata and timestamped snapshots into SQLite (UNIQUE item_id + date) to compute price changes and sales deltas.
04 · Automation
GitHub Actions & Pages
Runs pytest unit tests and refreshes the catalog every 3 days with record-count guardrails before deploying static JSON to GitHub Pages.
